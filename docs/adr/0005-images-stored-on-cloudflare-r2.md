# Images are stored on Cloudflare R2

The app runs on Heroku, whose filesystem is wiped on every restart, so Active Storage can't use the `:local` service that production was configured with. Lemon drop images go to Cloudflare R2 through Active Storage's S3 service: it's S3-compatible and has no egress fees for an image-heavy public page. The bucket is **public** (`public: true`) and served from a custom domain, so image URLs are permanent and cacheable. Active Storage's default signed URLs expire after a few minutes, which breaks Open Graph previews and browser caching, and proxying images through Heroku dynos would be slow. Every image is public content anyway. Uploads accept JPEG, PNG and WebP only. HEIC is left out because Heroku's libvips can't be relied on to decode it.
